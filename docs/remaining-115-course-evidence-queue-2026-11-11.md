# AnaMu — 115 cours encore partiels, recherche de matière par code

**11 novembre 2026.** Cette file actualise le triage précédent de 117 cours après acquisition du [modèle de Luce Beaudet](raw-batches/2026-11-11-udem-beaudet-tonal-analysis-primary-model.md), désormais suffisamment détaillé pour les deux cartes de MTE 12041/12042. L'attribution par semestre et les syllabus de section restent néanmoins inconnus.

**Registre principal : 263 exploitables / 115 partielles / 8 familles sur 386 entrées.** Parmi les 115 partielles, 90 sont historiquement `catalog_only`, 25 `partially_documented` et aucune `syllabus_documented`.
