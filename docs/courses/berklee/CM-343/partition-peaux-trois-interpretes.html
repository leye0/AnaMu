Peaux en relais - montage propose a trois

Partition d’attaques - proposition pédagogique originale AnaMu. Les affectations de mains et le montage sont à vérifier avec des interprètes.

Télécharger la partition MusicXML

  • P1 : congas, x E5 = aigu étouffé (GM62), tête normale E5 = aigu ouvert (GM63), C5 = grave (GM64); modes de frappe à vérifier.
  • P2 : bongos, E5 = aigu (GM60), C5 = grave (GM61); alternance de mains proposée.
  • P3 : x G5 = maraca, x C5 = tambourin; une main par accessoire, mode de tenue à préciser.
  • A : les bongos doublent les congas. B commence à M9 : les mêmes coups répondent une demi-mesure plus tard.
  • La croix de conga est une convention locale pour distinguer les commandes GM62 et GM63; elle ne certifie pas un geste acoustique.
  • Trois exécutants sont proposés pour inspecter les responsabilités; ni l’effectif minimal ni la jouabilité n’ont été validés.

Lecture rythmique : les débuts et simultanéités suivent le MIDI source. Les valeurs notées et silences décrivent une articulation proposée, pas les gates de 85/100/135 ticks du fichier. Un silence de déclenchement n’établit pas l’extinction acoustique. Parenthèses : vélocité inférieure à 50. Accent : commande de vélocité au moins 90, sans équivalence de décibels. MD/MG : main droite/gauche; PD/PG : pied droit/gauche. Les symboles de cette légende sont propres à cette partition.
