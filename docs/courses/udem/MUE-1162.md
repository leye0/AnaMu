# MUE 1162 — Atelier de musique contemporaine

Université de Montréal, option de pratique musicale. [Source de la carte propre au code](https://admission.umontreal.ca/cours-et-horaires/cours/mue-1162/). **Provenance :** description de programme et/ou page d'ensemble; aucun syllabus, œuvre imposée ou niveau technique précis de section n'a été recueilli. 12 novembre 2026.

## Matière musicalement attestée

La carte officielle associe au premier code un répertoire d'après 1950, le déchiffrage et les stratégies d'interprétation de notations récentes; le deuxième code est décrit comme laboratoire de création collective à contenu variable, sans langage compositionnel prescrit.

**Limite de niveau.** Chaque code conserve son objet propre (lecture contemporaine ou création collective), sans progression inventée. Le code `MUE 1162` est une option distincte; les autres niveaux de la famille ne lui transfèrent ni exercices ni répertoire.

## Application à l'analyse et à la création

### Apprentissage — Création contemporaine collective

**Analyse de musique existante — entrées, opérations et limites.** Réunir partition et captation d'une œuvre contemporaine réellement jouée; inventorier les types d'indications notées, entrées instrumentales, temporisations et gestes éventuels, puis noter lesquelles sont vérifiables en MIDI et lesquelles requièrent audio/vidéo. Pour le code de création collective, comparer deux versions de répétition sans inférer une technique obligatoire.

**Création/réinvestissement — construction et contrôle musical.** Concevoir une courte pièce collective originale en écrivant clairement contraintes, cues et répartition des décisions; l'essayer avec musiciens, enregistrer les versions, réviser les instructions confuses et expliquer les choix plutôt que de leur attribuer un système historique non sourcé.

**Démonstration et format approprié.** Aucun MIDI spécifique à cette section n'est justifié : il faudrait la partition, l'instrumentarium et/ou la captation réellement attribués à ce code. Les procédures de comparaison restent applicables au domaine attesté.
